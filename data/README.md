# Data Storage & Ingestion Module (data/)

This directory is reserved for data storage, schemas, and sample datasets in upcoming phases (Phase 1+).

### Directory Plan (Future Phases)
- `data/raw/`: Raw incoming transaction logs and SMS datasets
- `data/processed/`: Normalized and feature-engineered datasets
- `data/schemas/`: Data schema validation definitions

> **Note:** As per Phase 0 (Project Setup) specifications, no external databases or data pipelines are integrated yet.
